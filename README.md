# LKglobal Travel — Static GitHub Pages Site

This is a plain HTML/CSS/JavaScript landing page, so it can be hosted directly with GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — design and responsive layout
- `script.js` — mobile menu interaction

## Before launch
1. Replace the `DATE TBA` values with current trip dates.
2. Replace the Instagram and TikTok `href="#"` links with the real accounts.
3. Confirm the WhatsApp number and M-Pesa payment details.
4. For permanent image hosting, download your own photos into `/images/` and change the image URLs in `index.html` and `styles.css`.

## GitHub Pages
Push the files to the `lk-global-travel-safaris` repository, then open:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Your project site will normally be:
`https://rosemaina327.github.io/lk-global-travel-safaris/`
